# 1.6.2

- Fixed glitch and e-ink export by bundling the private mesh registration helper.
- Added an explicit optional holographic overlay and strength control for Parallax and Depth Map. Existing projects remain off by default.
- Added Clear Case: simulated layered plastic, frosted or glossy finish, tint, haze and internal movement controls. This uses an opaque approximation, not real transparency.
- Added RGB, one-colour and two-colour glitch palettes, with colour pickers. Corrected the runtime control-row mismatch.
- Requires SDEC 2.1.4 for these new settings. Put SDEC first in your mod list.
