# Deck Tool 1.9.2

Liquid in Glass now has a separate liquid colour picker. The selected colour is saved in projects, shown in the preview and retained in native deck exports independently of the glass tint. The existing Liquid Bottle colour control remains separate.

Install SDEC 3.4.2 separately and enable one copy first in the mod list to render custom liquid colours. Older Liquid in Glass decks keep their original teal appearance. Existing Glass, Clear Case and Crystal decks do not need re-exporting for this addition. Re-export a Liquid in Glass project when you want to apply a newly selected colour.

The local test pack was confirmed working in ReSkate Dev. Validation also covered the packaged application's colour picker, project save/reload and native export, every optical vertex in both shell sections at all six mesh levels, rendered colour output using compiled deck data, and the isolated mod merge. The shared core remains approximately 96.66 MiB installed, with no new textures or mesh streams for colour selection.
