# 1.6.1

- Fixed the preview worker's `copy` scope error, which prevented artwork previews from loading.
- Glitch previews now animate at a fixed viewing angle and pause when the window is hidden or minimized.
- E-ink and the default lenticular ridge finish are retained. No SDEC update is needed beyond 2.1.3.
- Clear Case authoring is not included in this release; the experimental simulated-shell decks remain separate.
