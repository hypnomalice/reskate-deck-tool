# ReSkate Deck Tool 1.5.0

- Dark Canvas Studio layout with a vertical deck list, always-visible effect selector, and Artwork / Effect / Finish tabs.
- Explicit upload buttons, precise size/position/rotation controls, optional linked layer transforms, and a viewing-angle slider beneath the preview.
- Dragging uses cached small images and coalesced preview updates; full effects refresh after release. Plain wheel scrolling no longer changes settings. Ctrl + wheel zooms artwork; Ctrl + Shift + wheel rotates it.
- Clickable help explanations. ZIP, FBMOD and Install to game remain available under Export as.

- CD Hologram is its own effect, with full-disc and corner layouts.
- Retains mirror/dyed backings; adds CD mirror with Original, Mirror contrast, Stronger diffraction and Combined responses.
- Separate artwork colours, adjustable depth and faint visibility, optional stronger backing rainbow and adjustable clear-layer sheen.
- Optional clear rim, recording-area boundary and zero to four hairline scratches, with strength controls.
- Optional white sheen for the other effects. Smooth depth transport and continuous Ghost Rare/parallax responses preserve intentional Enable lenticular banding.
- Matching shader runtime retains the close-up performance and startup improvements tested in game.

**Requires SDEC 2.1.0 or newer for the new finishes.** Update the existing Thunderstore core; enable one copy only. The app does not install or download it. No game DLL, compiler, private effect editor or sample artwork is bundled. Native ZIP export requires your external Studio compiler. CD preview lighting is approximate; reflections are authored rather than live scene mirrors.
