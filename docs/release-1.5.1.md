# ReSkate Deck Tool 1.5.1

CD Hologram artwork depth now uses centred movement, preserving relief between nearer and farther areas while reducing whole-image drift. The source depth map is preserved independently of the movement setting; zero movement stays still. New CD projects default to the accepted 120% movement setting. Existing saved strengths remain unchanged.

The preview now follows the accepted artwork response and the wider, brighter optional scratch finish. Scratch count/strength still control the exported finish, and zero strength or zero count remains clean. Rim and recording-area boundary follow the virtual disc; a corner layout may show only part of those features.

**Requires SDEC 2.1.1 for the updated CD behaviour. SDEC MUST BE NUMBER 1 IN YOUR MOD LIST.** Install/update SDEC separately through Thunderstore; it is not bundled in the tool. Other effect families and legacy CD atlas interpretation are retained. Depth-driven holo response remains experimental and is not enabled by normal tool exports.
