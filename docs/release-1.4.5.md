# ReSkate Deck Tool 1.4.5

- Visible Export as selector: Mod ZIP, Install to game, or FBMOD.
- Install directly into your selected game’s Mods folder, with a folder-name prompt for every install.
- Export the selected deck or the whole workspace, and remember the last export option.
- Safe updates back up unchanged tool exports and refuse to overwrite unrelated or edited mod folders.

ZIP and direct installation require a shader-capable Studio reskate_cli.exe, selected once in Export setup. The compiler is not bundled or downloaded. Close the game and launcher before installing, then enable the pack in the launcher.

SDEC remains a separate Thunderstore install. FBMOD export remains available for Studio editing. No new effects or custom game DLL are included.

Validation: 117 regression tests passed; packaged app checks cover export routing, custom folder naming, cancellation, previews and content-only output.
